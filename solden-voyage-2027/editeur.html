Alertes sur les téléphones

…

À chaque publication, les annonces sont programmées : les voyageurs qui ont activé les alertes reçoivent « Nouvelle annonce du groupe » à l’heure de l’annonce (au plus tôt 3 minutes après la publication). Le texte de l’annonce n’est jamais envoyé au service d’alertes.

Connexion à GitHub

non connecté

Créer le jeton (une seule fois)
  1. Sur github.com : photo de profil › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Nom : « Éditeur voyage ». Expiration : jusqu’après le voyage (ex. 30 avril 2027).
  3. Repository access : Only select repositories › choisissez le dépôt de l’app seulement.
  4. Permissions › Repository permissions › Contents : Read and write. Rien d’autre.
  5. Generate token, copiez-le (il commence par github_pat_) et collez-le ci-dessus.

Le jeton ne permet de modifier que ce dépôt. Il reste sur cet appareil et n’est jamais publié. En cas de perte du téléphone, supprimez-le dans la même page GitHub.

Phrase du voyage (accès protégé)

…

Avec une phrase, le contenu publié est chiffré : sans elle, personne ne peut lire le programme, les annonces, l’hôtel ni les liens du groupe. Les voyageurs l’entrent une seule fois sur leur téléphone. Restent publics : le titre, les dates, la météo et les webcams.

Lien d’invitation pour les voyageurs

Page d’installation avec le code QR et la phrase. À envoyer aux voyageurs seulement (courriel ou groupe WhatsApp), jamais en public.

Liste du groupe (accompagnateur seulement)

sur le téléphone

La liste du groupe ne passe plus par le site : aucune donnée des voyageurs n’est publiée, même chiffrée. Elle se gère dans l’app, sur votre téléphone : Infos › Accès accompagnateur. Importez-y un fichier CSV (Genre ; Nom ; Prénom ; Cellulaire ; Date de naissance ; Autre) ou ajoutez les personnes à la main. Elle reste sur ce téléphone seulement; gardez une copie du CSV pour la réimporter au besoin.
