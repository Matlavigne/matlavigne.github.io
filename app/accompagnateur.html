Connexion

Avec le compte remis par le responsable de l’app. Vous restez connecté 30 jours sur ce téléphone.

Code de vérification

Entrez le code à 6 chiffres de votre app d’authentification, ou un code de secours.

Choisissez votre mot de passe

Remplacez le mot de passe temporaire par le vôtre (10 caractères ou plus). Une courte phrase est plus facile à retenir et plus sûre.

Double authentification

Obligatoire pour tous les comptes : elle protège l’éditeur de vos voyages. Installez d’abord une app d’authentification (Google Authenticator, Microsoft Authenticator, 1Password ou l’app Mots de passe de l’iPhone), puis activez-la. Deux minutes, une seule fois.

Installer l’app Mon accompagnateur

iPhone : dans Safari, touchez Partager, puis « Sur l’écran d’accueil ». Android : menu ⋮ de Chrome, puis « Installer l’application ».

Ouvrez vos voyages, l’éditeur et Mon groupe à partir de cette app : sur iPhone, chaque app de l’écran d’accueil garde ses propres données. La liste du groupe importée ici reste ici.

Les listes de groupe restent sur le téléphone de l’accompagnateur : elles ne passent jamais par Internet.
