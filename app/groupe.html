Aucune liste sur ce téléphone

Importez un fichier CSV (exporté d’Excel) ou ajoutez les personnes une à une. Colonnes : Genre ; Nom ; Prénom ; Cellulaire ; Date de naissance ; Autre. Une ligne d’en-tête est reconnue; sans en-tête, cet ordre est utilisé.

Ajouter une personne

Les présences sont gardées sur ce téléphone seulement : chaque accompagnateur fait son propre appel.

Gérer la liste

Gardez une copie du fichier CSV : si les données du téléphone sont effacées ou si vous changez de téléphone, il suffit de le réimporter. Après le retour (au plus tard 30 jours), touchez « Effacer la liste » et supprimez aussi vos copies du fichier, comme le prévoit la politique de confidentialité.

Clé d’équipe

La liste et les présences sont chiffrées avec une clé aléatoire (AES-256) gardée seulement sur les téléphones des accompagnateurs du voyage. Le serveur conserve une copie chiffrée qu’il ne peut pas lire.

Le code de secours est cette clé, écrite en clair. Gardez-le dans votre gestionnaire de mots de passe : il rouvre la liste si tous les téléphones qui ont la clé sont perdus. Ne l’envoyez à personne.

La liste et les présences restent dans cette app, sur ce téléphone, tant qu’elles ne sont pas partagées.
