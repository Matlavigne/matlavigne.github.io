Ouvrir l’app

iPhone VOTRE TÉLÉPHONE

Avec Safari

  1. Ouvrez l’adresse dans SafariEn scannant le code ou en touchant le lien reçu.
  2. Touchez Partager En bas de l’écran (ou en haut sur iPad).
  3. Choisissez « Sur l’écran d’accueil » Faites défiler la liste vers le bas si vous ne le voyez pas.
  4. Touchez « Ajouter »L’icône St. Anton apparaît avec vos autres apps.

Android VOTRE TÉLÉPHONE

Avec Chrome

  1. Ouvrez l’adresse dans ChromeEn scannant le code ou en touchant le lien reçu.
  2. Touchez le menu Les trois points en haut à droite.
  3. Choisissez « Installer l’application »Ou « Ajouter à l’écran d’accueil ». Chrome le propose parfois tout seul dans un bandeau en bas.
  4. Confirmez « Installer »L’icône St. Anton apparaît avec vos autres apps.

Activer les alertes du voyage

Recevez les annonces du groupe (changement d’horaire, rendez-vous déplacé) même quand l’app est fermée. Seulement les annonces de votre accompagnateur : aucune publicité.

  1. Ouvrez l’app depuis son icôneSur l’écran d’accueil, pas dans Safari ni Chrome. Sur iPhone, c’est obligatoire : les alertes ne fonctionnent que dans l’app installée.
  2. Roue dentée ⚙ en haut à droite › « Alertes du voyage »Touchez « Activer les alertes ».
  3. Touchez « Autoriser »Quand le téléphone demande la permission d’envoyer des notifications.
  4. C’est toutVous recevrez « Nouvelle annonce du groupe ». Une pastille rouge sur l’icône compte les annonces que vous n’avez pas encore lues.

Pas de demande d’autorisation, ou alertes bloquées? iPhone : Réglages › Notifications › St. Anton › Autoriser les notifications. Android : touchez longuement l’icône › Infos sur l’app › Notifications. Pour arrêter les alertes : onglet Infos, « Désactiver les alertes » (touchez deux fois pour confirmer).

Une fois installée

  • Ouvrez l’app une première fois avec Internet : elle se garde ensuite en mémoire et fonctionne même sans réseau.
  • Touchez « Ma position » dans l’onglet Carte et autorisez la localisation pour vous situer sur les pistes.
  • Les annonces du groupe s’affichent sur l’Accueil. Avec les alertes activées, vous êtes averti; sinon, ouvrez l’app chaque matin pendant le voyage.
  • Rejoignez le groupe WhatsApp et le groupe Facebook depuis l’Accueil, dès que les liens sont disponibles.

Ça ne fonctionne pas?

  • iPhone : « Sur l’écran d’accueil » n’apparaît pas? Vérifiez que la page est ouverte dans Safari, et non depuis une autre app (Facebook, Messenger, courriel). Touchez « Ouvrir dans Safari » au besoin.
  • Android : pas d’option « Installer »? Mettez Chrome à jour dans le Play Store, ou utilisez « Ajouter à l’écran d’accueil ».
  • Vous pouvez aussi simplement garder l’adresse en favori : tout fonctionne aussi dans le navigateur.
  • Toujours bloqué? Écrivez à votre accompagnateur, il vous aidera au cocktail de bienvenue.
